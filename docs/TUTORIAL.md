# GroupViz Tutorial — Using the App

> 中文版教程见 [TUTORIAL_zh-CN.md](TUTORIAL_zh-CN.md)（简体中文）。

This guide walks you through GroupViz from zero: picking a group, reading the views,
building new groups, and verifying the classical theorems visually. It is written for
mathematicians, students, and hobbyists — no prior experience with the app is assumed.

A short reminder before we start: every mathematical symbol in the app is rendered by
KaTeX, and the visual conventions (Cayley graphs, cosets, symmetry views) follow
*Visual Group Theory* by Nathan Carter.

---

## 1. Quick start

1. Install dependencies and start the dev server:

   ```bash
   npm install
   npm run dev
   ```

2. Open the URL printed in your terminal (Vite's default is `http://localhost:5173`).
3. You land on the welcome page. There you can switch the UI language (中文 / English)
   and the theme (dark / light). Click the entry button to open the workspace.

The backend is **optional** for the first steps: groups of order ≤ 60 are computed
entirely in the browser. Only when you explore very large groups (|G| > 60) is a small
FastAPI backend used — see [§13 Troubleshooting](#13-troubleshooting-and-performance)
to start it.

---

## 2. The workspace at a glance

The workspace is a three-column workbench.

**Left panel** (top to bottom, collapsible sections):

| Section | What it does |
|---|---|
| 视图模式 (View Modes) | The 9 view cards + export tools |
| 操作与子集 (Operations) | 4 tabs: general / subset→subgroup / quotient / automorphism |
| 基本群 (Basic Groups) | Create groups: by family, special groups, by order |
| 直积 (Direct Product) | Build G × H |
| 同态 (Homomorphism) | Define and verify group homomorphisms |
| 群作用 (Group Actions) | 5 action sources + orbit analysis |
| 半直积 (Semidirect Product) | Build N ⋊_φ H |
| 群展示 (Group Presentation) | Define groups by generators & relators |

**Center canvas**: the current group in the current view (13 modes in total).

**Right panel**: the information side. It shows the group's symbol, order, generators,
abelian/structure info, center, solvable/nilpotent/perfect badges and presentation; below
that the subgroup list and conjugacy class list (accordions); and the element list.
Clicking an element anywhere selects it and the panel shows its order, inverse, etc.

**Top bar**: theme toggle, language toggle. Your session (current group + view) is
saved to `localStorage` automatically and restored on reload.

## 3. Lesson 1 — Pick a group (5 minutes)

In **基本群 (Basic Groups)**, three creation tabs:

- **按类型 (By family)** — C_n (n = 2–120), S_n (n = 2–5), D_n (n = 3–8), A_n (n = 3–5).
- **Special groups** — V₄, Q₈, GL(2,2) ≅ S₃, GL(2,3) (order 48, a matrix group).
- **按阶 (By order)** — every group of order 1–31 from the GAP SmallGroups registry
  (93 groups in total), plus A₅ (order 60) and S₅ (order 120). The `:` inside a symbol
  signals a semidirect product (hover for a hint).

**Try this:** create D₄ (dihedral, n = 4, order 8). Watch the right panel: order,
generators, structure (直积/半直积/不可分解), center Z(G), presentation. Then switch
to by-order mode and load the same order-8 groups (C₈, C₄×C₂, Q₈, D₄…) and compare
their info panels — generators and center differ in revealing ways.

Every constructed group (direct/semidirect product, quotient, Aut(G), presentation)
can later be reloaded from the list inside its own panel.

## 4. Lesson 2 — Six core views (15 minutes)

The 9 view cards live in **视图模式 (View Modes)**. Six of them teach you the most:

### 4.1 set — element list
All elements with labels; click one to select it (its properties appear in the right
panel). Use ←/→/↑/↓ to cycle the selection.

### 4.2 cayley — 2D Cayley graph
Nodes are the group elements; colored edges show multiplication by each generator
(right multiplication by default; colors follow a fixed 16-color palette).

- In **凯莱图设置 (Cayley settings)** you can flip between 右乘 (right) and 左乘 (left)
  multiplication, toggle individual acting elements (this is the *generalized* Cayley
  graph — the acting set need not generate the group!), pick a 2D shape, and control
  animation speed.
- The shape is chosen automatically (12 layouts: circular, grid, rewiring, concentric,
  cylinder/torus for direct products, …) but you can override it from the dropdown.
- Drag to pan, wheel to zoom, double-click an empty spot to reset.

**Try:** on D₄, remove one generator from the acting set and watch the graph change;
add an element of order 2 back and see the edges double.

### 4.3 cycle — cycle graph
Shows the cyclic structure of the group: elements grouped into cycles generated by
powers. Fastest way to spot elements of order 2, 3, 4 and to see C_n subgroups inside
a bigger group. Try it on C₆ × C₂ and on Q₈.

### 4.4 table — multiplication table
A Cayley table. Click a cell to see the product g·h. For |G| > 16 a strategy bar
appears at the top:

| Strategy | What it shows |
|---|---|
| Subgroup display (default) | A chosen small subgroup (6–12 elements) |
| Random display | A random sampling |
| Full display | The complete n×n table — confirm, then a **fullscreen** modal opens with a zoom slider (25%–600%), pan, SVG export; Esc exits back to subgroup display |

For |G| > 30 the full display asks for confirmation first.

### 4.5 3d — 3D Cayley graph
A Three.js scene. The 3D shape is auto-picked from 17 templates (spherical, lattice,
torus, semidirect cylinder, hypercube for C₂⁴, …) and can be overridden from the
dropdown.

Camera controls: **left-drag** rotates (you may flip over the poles — the view stays
upright automatically), **right-drag** pans, **wheel** zooms (clamped to the bounding
sphere of the node cloud), ▶ **auto-rotates**, double-click resets the fitted view.

### 4.6 symmetry — polyhedral view
Only meaningful for geometric groups (try D₃, D₄, A₄, A₅, S₄). Picks a polyhedron whose
symmetry group matches, lets you pick an element, and animates its operation
(rotations/reflections) with marked axes; speed slider included. This view also exports
GIF animations.

**Controls recap** for 2D views: drag = pan, wheel = zoom, double-click = reset.
For the 3D view: left-drag = orbit, right-drag = pan, wheel = zoom, ▶ = auto-rotate,
double-click = reset.

## 5. Lesson 3 — Subgroups, cosets, the lattice (10 minutes)

### 5.1 sublattice — the subgroup lattice
The Hasse diagram of all subgroups. The center Z(G) is highlighted gold with a Z(G)
badge (also reflected in the subgroup list). From the bottom series bar you can overlay
four subgroup chains at once:

- **导列** derived series, **上/下中心列** upper/lower central series, **合成列**
  composition series (Jordan–Hölder).

Series members get colored outlines; the chain is displayed as TeX
`G ⊵ N₁ ⊵ … ⊵ ⟨e⟩` with orders and factor groups `Nᵢ/Nᵢ₊₁ ≅ …`, plus solvable/nilpotent
badges. The composition series also lists its factor multiset (for |G| small enough,
all composition series are enumerated and switchable).

### 5.2 cosetstrip — cosets and Lagrange
Pick a subgroup H from the right panel's subgroup list. The canvas shows the cosets
xH as horizontal strips, with the subgroup's own circular Cayley graph ⟨H⟩ on top —
a direct visual check of **Lagrange's theorem**: |G| = |H| · [G:H].

### 5.3 subset → subgroup, normalizer, centralizer (Operations panel)
In **操作与子集**, select a subset E ⊂ G (click elements) and:

- **由子集生成 ⟨E⟩** — computes the subgroup generated by E and jumps to the coset
  strip with the Lagrange readout.
- **正规化子 N_G(E)**, **中心化子 C_G(E)** — one click each; results open in the
  coset strip too.

The two other tabs of this panel:

- **商群 (Quotient)** — choose a normal subgroup N (from the subgroup list) and create
  G/N; the result appears in the quotient group list and can be loaded as the current
  group.
- **自同构 (Automorphism)** — `compute Aut(G)` builds the automorphism group (with an
  order guard); load it and explore it like any group — selecting an automorphism
  element shows its full mapping table in the right panel.

## 6. Lesson 4 — Build larger groups (10 minutes)

### 6.1 Direct product G × H
In **直积**, pick two groups (any group you have created is available), hit create.
The 2D layout becomes a grid (two cyclic factors), a cylinder (one cyclic factor —
concentric staggered rings), or a torus (no cyclic factors, nested rings); 3D versions
exist too. Try C₂ × C₂, C₆ × C₂, and D₄ × D₄.

### 6.2 Semidirect product N ⋊_φ H
In **半直积**: pick N and H, then define φ: H → Aut(N) by choosing, for each generator
of H, an automorphism of N (visual mapping UI). A 4-step build animation shows the
construction. The default **rewiring** layout draws one disk per copy of N and reconnects
the spokes according to the twist φ(h); fixed points of the twisting are highlighted.
Try QD16 (C₈ ⋊ C₂ with φ twisting a³) vs. the plain product C₈ × C₂ and compare the
spoke patterns.

Note: registry groups whose symbol contains `:` (e.g. `(Z₄×Z₂):Z₂`, `C₈:C₂`) are
automatically decoded into N/H/φ — their default view is already the rewiring layout.

### 6.3 Presentations — define a group by generators and relators
In **群展示** you can create a group from a presentation in two ways:

1. **直接创建** — type complete relator text like `⟨a,b | a², b², (ab)³⟩`
   (Unicode superscripts like `a²`, `a⁻¹`, and equations `ab = ba` are supported).
2. **可视化创建** — pick 1/2/3 generator template, add relators one at a time, and watch
   the live order check (order, ≅-guess, finite/infinite verdict) as each relator is
   added; then “create group”.

New presentation groups open two dedicated views (entry buttons at the bottom of the
presentation panel — they are *not* view cards):

- **tree (群树)** — the BFS spanning tree of the Cayley graph built from the relators:
  solid edges are first-arrival edges (colored by generator); glued edges are **not**
  drawn, they are only counted in the gold bar “glued edges × N” — this is the classic
  “relations = cutting the tree” picture. Layout is regularized: one generator → a line,
  two generators with commuting relations → a grid, otherwise a Sierpiński-like cross,
  three generators → 3D. Click a node to see its word.
- **prestable (展示乘法表)** — the multiplication table of the presentation group with
  the relator bar on top (auto-sampled when the order is large).

## 7. Lesson 5 — Homomorphisms and the First Isomorphism Theorem (5 minutes)

In **同态 (Homomorphism)**:

1. Pick the source group and the target group.
2. Map the *generators* of the source (dropdowns), or use the **auto-map** menu
   (trivial map, projection onto a direct-product factor, …).
3. Press **verify** — the app checks the homomorphism property on all pairs and reports
   ✓ or ✗ (with the violating pair localized).
4. The right panel then shows kernel, image, and the quotient G/ker, and compares
   G/ker ≅ im — the First Isomorphism Theorem.
5. Run the four-stage animation (G → G/ker → im → H) in the canvas.

Try the projection S₄ → S₃ (kernel V₄) or the sign homomorphism S₃ → C₂.

## 8. Lesson 6 — Group actions and the orbit view (10 minutes)

In **群作用 (Group Actions)** pick one of five action sources:

| Source | Meaning | Signature observation |
|---|---|---|
| Conjugation | G acts on itself by g·x = gxg⁻¹ | Fixed points = center Z(G) |
| Regular (left translation) | G acts on itself by g·x = gx | **Cayley's theorem** — one free orbit, Stab(x) = {e} |
| Coset action | G acts on the cosets G/H (pick H) | Transitive; Stab(xH) = xHx⁻¹ ≅ H |
| Sylow | G acts on its Sylow p-subgroups | Orbit size = n_p, stabilizer = normalizer |
| Custom | You define g·x by clicking | Interactive arrow editor, draft auto-saved |

The **orbit view** draws the orbits as clusters with generator-colored edges; hover a
node to see all arrows leaving it; fixed points get a ★. The right panel lists orbit
sizes and stabilizers and runs two self-checks:

- **Orbit–Stabilizer Theorem**: |G| = |O| · |Stab(x)| per orbit (green ✓).
- **Burnside's lemma**: |X/G| = (1/|G|) · Σ|Fix(g)|.

Saving an action persists it per group (it appears again after reload or group switch).

## 9. Lesson 7 — Sylow theory (10 minutes)

The **sylow** view runs the whole Sylow workflow visually:

1. Pick a prime p dividing |G| (dropdown).
2. The canvas shows p-elements first; then all p-subgroups are built
   (cyclic p-subgroups → closed under pairwise joins), with **Sylow p-subgroups**
   marked by ★.
3. The panel verifies **Sylow theorems numerically**: n_p ≡ 1 (mod p), n_p | m
   (where |G| = p^k · m), and |N_G(P)| = |G| / n_p for the normalizer order.
4. Select **two** Sylow subgroups (Ctrl/⌘-click or the ⊕ button) — they appear stacked
   vertically with a conjugation arrow gPg⁻¹ = Q (the app finds such a g itself):
   **Sylow's second theorem**, visualized.
5. Select a single p-subgroup to see the coset strip layout with |G| = |P| · [G:P].

Finally, run G's conjugation action on Syl_p(G) in the orbit view to verify the action
on the set of Sylow subgroups (orbit = all Sylow p-subgroups, stabilizer = normalizer).

## 10. Export and multi-view windows

- **Export** (top of the view section): SVG for 2D views, PNG for 3D, and GIF for the
  symmetry animation and for the 3D Cayley graph.
- **3D Cayley GIF**: choose “约 3 秒 (~3 seconds)” or “5 cycles”. The export runs on an
  off-screen renderer, whose rotation speed is matched to the ▶ auto-rotate speed you
  see, and always completes whole turns — the result loops seamlessly. The live view
  keeps rotating while the GIF is assembled.
- **Floating windows**: open the current view in its own draggable window to compare
  views side by side.
- **Batch export CLI**: `npm run export` (Playwright) exports configured views of
  configured groups into `exports/batch-<timestamp>/`.

## 12. Suggested learning paths by goal

| Goal | Path |
|---|---|
| Understand Lagrange's theorem | sublattice → pick H → cosetstrip |
| See Cayley's theorem | 群作用: regular action + orbit view |
| First isomorphism theorem | 同态 panel: define, verify, animate |
| Orbit–Stabilizer | 群作用: any action + orbit view self-check |
| Sylow theorems | sylow view (both-subgroup mode) |
| Subgroup structure / solvability | sublattice + series bar (derived / central / composition) |
| What a presentation really means | 群展示: build ⟨a,b | …⟩ → tree view |
| Generalized Cayley graphs | cayley view + 凯莱图设置 acting set |

A good default rotation to practice on: D₄ → S₃ → A₄ → S₄ → C₆×C₂ → Q₈ → GL(2,3),
then try the constructions (C₂×S₃, S₃⋊C₂, QD16) and, finally, a presentation like
`⟨a,b | a⁴, b², ab = ba⟩`.

## 13. Troubleshooting and performance

- **Large groups** (|G| > 60): the app first tries the FastAPI backend. If it is not
  running it falls back to local computation (up to order 240; S₅ takes ~2–3 s) and a
  progress bar appears at the top for slow jobs. To enable the fast path:

  ```bash
  cd backend
  pip install -r requirements.txt
  uvicorn main:app --reload --port 8000
  ```

- **Session restore**: the current group and view are persisted locally; a page refresh
  brings you back where you were. Custom action drafts and presentation drafts are
  also auto-saved.
- **A layout looks tangled**: switch the 2D shape manually (12 layouts), or the 3D shape
  (17 templates) — for product/semidirect groups the cylinder/torus/rewiring presets
  are usually the readable ones.
- **Subgroups of very large groups** may come from the backend; the right panel shows a
  loading hint while fetching.
