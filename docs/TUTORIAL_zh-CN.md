# GroupViz 新手教程 — 从零上手

> English version: [TUTORIAL.md](TUTORIAL.md)。

本教程带你从零开始掌握 GroupViz：如何选择群、读懂各视图、构建新群，以及用可视化的
方式验证群论中的经典定理。目标读者是数学研究者、学生与爱好者——不需要任何使用本
应用的经验。

开始前先记住两点：应用内所有数学符号均由 KaTeX 渲染；所有可视化约定（凯莱图、陪集、
对称性视图）以 Nathan Carter 所著《群论彩图版》（Visual Group Theory）为准。

---

## 1. 快速开始

1. 安装依赖并启动开发服务器：

   ```bash
   npm install
   npm run dev
   ```

2. 打开终端输出的网址（Vite 默认为 `http://localhost:5173`）。
3. 首先看到欢迎页，可以在那里切换界面语言（中文 / English）与主题（深色 / 浅色），
   然后点击进入按钮打开工作台。

前几步**不需要后端**：阶 ≤ 60 的群全部在浏览器本地计算。只有探索超大群（|G| > 60）
时才需要启动一个轻量 FastAPI 后端——开启方法见 [§13 疑难解答与性能](#13-疑难解答与性能)。

---

## 2. 工作台一览

工作台是三栏布局。

**左侧面板**（从上到下，可折叠分区）：

| 分区 | 作用 |
|---|---|
| 视图模式 | 9 张视图卡片 + 导出工具 |
| 操作与子集 | 4 个 tab：通用 / 子集生成子群 / 商群 / 自同构 |
| 基本群 | 创建群：按类型、特殊群、按阶 |
| 直积 | 构建 G × H |
| 同态 | 定义并验证群同态 |
| 群作用 | 5 种作用来源 + 轨道分析 |
| 半直积 | 构建 N ⋊_φ H |
| 群展示 | 用生成元与关系定义群 |

**中间画布**：当前群、当前视图（共 13 种视图模式）。

**右侧信息面板**：群的信息——符号、阶、生成元、交换性/结构、中心、可解/幂零/完美
徽标与展示（presentation）；下方是子群列表与共轭类列表（可折叠）以及元素列表。
在任何视图中点击一个元素即可选中，右侧会显示它的阶、逆元等信息。

**顶部栏**：主题切换、语言切换。当前会话（群 + 视图）会自动存入 `localStorage`，
刷新页面后自动恢复。

## 3. 第一课：选一个群（5 分钟）

在「基本群」面板中有三种创建方式：

- **按类型创建**：C_n（n = 2–120）、S_n（n = 2–5）、D_n（n = 3–8）、A_n（n = 3–5）。
- **特殊群**：V₄、Q₈、GL(2,2) ≅ S₃、GL(2,3)（48 阶矩阵群）。
- **按阶创建**：阶 1–31 的全部 93 个群（GAP SmallGroups 注册表），外加 A₅（60 阶）
  与 S₅（120 阶）。符号中出现 `:` 表示半直积结构（可悬停查看提示）。

**试一试**：创建 D₄（二面体群，n = 4，8 阶）。观察右侧面板：阶、生成元、结构
（直积/半直积/不可分解）、中心 Z(G)、展示。再切到按阶创建，把同阶的 C₈、C₄×C₂、
Q₈、D₄ 都加载一遍，对比它们的信息面板——生成元与中心的不同之处非常说明问题。

所有构建出来的群（直积/半直积、商群、Aut(G)、展示群）都可以在各自面板的列表中
随时重新加载。

## 4. 第二课：六个核心视图（15 分钟）

「视图模式」面板有 9 张卡片，其中 6 个最值得先熟悉：

### 4.1 集合视图（Set View）
元素清单。点击选中某个元素（右侧面板显示其性质），用 ←/→/↑/↓ 键循环切换选中项。

### 4.2 凯莱图（2D Cayley Graph）
节点是群的元素，彩色边表示与各个生成元右乘（默认右乘；颜色来自固定的 16 色调色板）。

- 在「凯莱图设置」里可以切换**右乘/左乘**、增减作用元素（这是**广义**凯莱图——
  作用集不要求生成整个群！）、选择 2D 形状、调整动画速度。
- 形状自动分配（共 14 种 2D 布局：圆形、网格、重布线、同心圆、直积的圆柱/甜甜圈等），
  也可以手动下拉覆盖。
- 拖拽平移、滚轮缩放、双击空白复位。

**试一试**：在 D₄ 上从作用集中去掉一个生成元观察图的变化，再把一个 2 阶元素加回来，
边数立刻翻倍。

### 4.3 循环图（Cycle Graph）
展示群的循环结构：元素按生成元的幂分成一个个环。这是最快发现 2 阶/3 阶/4 阶元素、
以及在更大的群里看到 C_n 子群的方式。试试 C₆ × C₂ 和 Q₈。

### 4.4 乘法表（Multiplication Table）
Cayley 表。点击单元格查看乘积 g·h。当 |G| > 16 时顶部出现策略栏：

| 策略 | 内容 |
|---|---|
| 子群展示（默认） | 挑选一个小子群（6–12 个元素）|
| 随机展示 | 随机抽样 |
| 全量展示 | 完整 n×n 表——确认后打开**全屏**模态框：缩放滑块（25%–600%）、平移、导出 SVG；Esc 退出并回到子群展示 |

当 |G| > 30 时全量展示会先弹确认框。

### 4.5 3D 凯莱图
Three.js 场景。3D 形状自动分配（共 18 种模板：圆锥、格点、torus、半直积圆柱、
C₂⁴ 超立方体等），可下拉覆盖。

相机操作：**左键拖拽**旋转（可以翻越上下两极——画面会自动保持正立），**右键拖拽**
平移，**滚轮**缩放（自动钳制在节点云外接球之外），▶ **自动旋转**，双击复位到适配视角。

### 4.6 对称性视图（Symmetry View）
仅对几何群有意义（试试 D₃、D₄、A₄、A₅、S₄）。为群匹配一个多面体，选中元素后动画
演示它的作用（旋转/反射），并标记旋转轴；含速度滑块，支持 GIF 导出。

**控制速记**：2D 视图——拖拽平移、滚轮缩放、双击复位；3D 视图——左键旋转、
右键平移、滚轮缩放、▶ 自动旋转、双击复位。

## 5. 第三课：子群、陪集与子群格（10 分钟）

### 5.1 子群格（Subgroup Lattice）
全部子群的 Hasse 图。中心 Z(G) 金色高亮并带 Z(G) 角标（右侧子群列表也有中心徽章）。
底部系列条可以同时叠加四种子群列：

- **导列**（derived series）、**上/下中心列**（upper/lower central series）、
  **合成列**（composition series，Jordan–Hölder）。

系列成员节点彩色描边；系列以 TeX 链式展示 `G ⊵ N₁ ⊵ … ⊵ ⟨e⟩`，含各级阶与因子群
`Nᵢ/Nᵢ₊₁ ≅ …`，并标注可解/幂零徽标。合成列额外列出合成因子多重集（小群会枚举全部
合成列并可切换选择）。

### 5.2 陪集条带（Coset Strip）与 Lagrange 定理
在右侧子群列表中选一个 H。画布把陪集 xH 画成水平条带，条带上方展示 H 自己的圆形
凯莱图 ⟨H⟩——这就是对 **Lagrange 定理** |G| = |H| · [G:H] 最直接的视觉验证。

### 5.3 子集生成子群、正规化子、中心化子（操作面板）
在「操作与子集」中点击元素选中一个子集 E ⊂ G，然后：

- **由子集生成 ⟨E⟩**：一键计算由 E 生成的子群，并自动跳转到陪集条带展示 Lagrange
  关系。
- **正规化子 N_G(E)** 与 **中心化子 C_G(E)**：各一键求出，同样跳到陪集条带。

该面板另外两个 tab：

- **商群**：从子群列表选一个正规子群 N，创建 G/N；结果出现在商群列表中，可加载为
  当前群。
- **自同构**：一键 `compute Aut(G)` 构建自同构群（有序数守卫）；加载后像普通群一样
  探索——选中一个自同构元素，右侧面板会展示它的完整映射表。

## 6. 第四课：构建更大的群（10 分钟）

### 6.1 直积 G × H
在「直积」面板选两个群（之前创建的任何群都可选）创建。2D 布局自动分类：全循环因子
→ 网格（grid）；恰一个循环因子 → 圆柱（cylinder，交错同心圆）；全非循环因子 →
甜甜圈（torus，嵌套环）；3D 也有对应形状。试试 C₂×C₂、C₆×C₂ 与 D₄×D₄。

### 6.2 半直积 N ⋊_φ H
在「半直积」面板：选 N 与 H，然后为 H 的每个生成元选一个 N 的自同构，定义
φ: H → Aut(N)（可视化映射界面）。4 步构建动画演示构造过程。默认 **rewiring（重布线）**
布局把 N 的每个副本画成一个盘，盘间辐条按扭转 φ(h) 重新连接；扭转的不动点会高亮。
对比 QD16（C₈ ⋊ C₂，φ 扭转 a³）与普通直积 C₈ × C₂，观察辐条连接模式的不同。

注意：符号含 `:` 的注册表群（如 `(Z₄×Z₂):Z₂`、`C₈:C₂`）会被自动解码为 N/H/φ，
默认形状就是重布线。

### 6.3 群展示——用生成元与关系定义群
在「群展示」面板有两种创建方式：

1. **直接创建**：输入完整展示文本，如 `⟨a,b | a², b², (ab)³⟩`（支持 Unicode 上标
   `a²`、`a⁻¹`，以及等式 `ab = ba`）。
2. **可视化创建**：选 1/2/3 个生成元的模板，逐步添加单条关系，添加的同时实时校验
   （阶、≅ 猜测、有限/无限判定），最后「结束并创建群」。

创建的新群会打开两个专用视图（入口在群展示面板底部，不是视图卡片）：

- **群树（tree）**：由关系构造的凯莱图 BFS 生成树——实线是首次到达的边（按生成元
  着色）；粘合边**不绘制**，只在顶部金色 bar 计数「粘合边 × N」。这正是「关系 = 砍树」
  的经典图景。布局规则化：1 个生成元 → 直线；2 个生成元且交换 → 网格；否则 →
  谢尔宾斯基式十字；3 个生成元 → 3D。点击节点查看其词。
- **展示乘法表（prestable）**：该展示群的乘法表，顶部有静态的关系 bar（阶较大时
  自动采样）。

## 7. 第五课：同态与第一同构定理（5 分钟）

在「同态」面板：

1. 选择源群与目标群。
2. 映射源群的**生成元**（下拉选择），或用**自动映射**菜单（平凡映射、直积因子投影等）。
3. 点击**验证**——程序检查全部元素对是否满足同态性质，报告 ✓ 或 ✗（并指出违规对）。
4. 右侧面板显示核、像与商群 G/ker，并比较 G/ker ≅ im——即第一同构定理。
5. 在画布上运行四阶段动画（G → G/ker → im → H）。

试试投影 S₄ → S₃（核为 V₄），或符号同态 S₃ → C₂。

---

## 8. 第六课：群作用与轨道视图（10 分钟）

在「群作用」面板选择五种作用来源之一：

| 来源 | 含义 | 标志性观察 |
|---|---|---|
| 共轭作用 | g·x = gxg⁻¹ | 不动点 = 中心 Z(G) |
| 正则作用（左平移） | g·x = gx | **Cayley 定理**——唯一自由轨道，Stab(x) = {e} |
| 陪集作用 | G 作用于陪集 G/H（选 H） | 传递；Stab(xH) = xHx⁻¹ ≅ H |
| Sylow 作用 | G 作用于 Sylow p-子群 | 轨道大小 = n_p，稳定子 = 正规化子 |
| 自定义 | 点击定义 g·x | 交互式箭头编辑，草稿自动保存 |

**轨道视图**把轨道画成簇布局，簇内是生成元着色边；悬停节点显示全部出箭头；不动点
标 ★。右侧面板列出各轨道大小与稳定化子，并执行两项自检：

- **轨道-稳定化子定理**：每个轨道满足 |G| = |O| · |Stab(x)|（绿色 ✓）。
- **Burnside 引理**：|X/G| = (1/|G|) · Σ|Fix(g)|。

已保存的作用会按群持久化（刷新或切群后仍可从面板列表加载）。

## 9. 第七课：Sylow 定理（10 分钟）

**sylow** 视图完整走一遍 Sylow 工作流：

1. 选一个整除 |G| 的素数 p（下拉）。
2. 画布先展示 p-元素；再逐步构造全部 p-子群（循环 p-子群 → 两两 join 闭包），
   **Sylow p-子群**以 ★ 标记。
3. 面板数值验证 Sylow 定理：n_p ≡ 1 (mod p)、n_p | m（|G| = p^k · m），以及
   正规化子阶 |N_G(P)| = |G| / n_p。
4. 单选一个子群 → 陪集条带布局（|G| = |P| · [G:P]）；**Ctrl/⌘ 或 ⊕ 复选两个**
   Sylow 子群 → 上下布局 + 竖直共轭箭头 gPg⁻¹ = Q（程序自动求出这样的 g）——
   这就是可视化的 **Sylow 第二定理**。
5. 最后在轨道视图里跑一遍 G 对 Syl_p(G) 的共轭作用，验证该作用（轨道大小 = n_p，
   稳定子 = 正规化子）。

## 10. 导出与多视图窗口

- **导出**（视图区顶部）：2D 视图导出 SVG，3D 导出 PNG，GIF 支持对称性动画与
  3D 凯莱图。
- **3D 凯莱图 GIF**：时长可选「约 3 秒」或「5 个旋转周期」。导出在**离屏渲染器**上
  进行，转速与展示区 ▶ 自动旋转完全一致，且总转角恒为整圈——动图无缝循环；导出期间
  展示区照常旋转。
- **多视图浮动窗口**：把当前视图弹出为独立的可拖拽窗口，便于并排对照。
- **批量导出 CLI**：`npm run export`（Playwright）按配置批量导出到
  `exports/batch-<时间戳>/`。

## 12. 按目标推荐的学习路径

| 目标 | 路径 |
|---|---|
| 理解 Lagrange 定理 | 子群格 → 选 H → 陪集条带 |
| 看 Cayley 定理 | 群作用：正则作用 + 轨道视图 |
| 第一同构定理 | 同态面板：定义 → 验证 → 动画 |
| 轨道-稳定化子 | 群作用：任选作用 + 轨道视图自检 |
| Sylow 定理 | sylow 视图（双子群模式）|
| 子群结构 / 可解性 | 子群格 + 系列条（导列/中心列/合成列）|
| 展示到底是什么 | 群展示：构建 ⟨a,b | …⟩ → 群树视图 |
| 广义凯莱图 | 凯莱图 + 凯莱图设置的作用集 |

建议的练习轮换：D₄ → S₃ → A₄ → S₄ → C₆×C₂ → Q₈ → GL(2,3)，再做构建
（C₂×S₃、S₃⋊C₂、QD16），最后做一个展示群，比如 `⟨a,b | a⁴, b², ab = ba⟩`。

## 13. 疑难解答与性能

- **大群（|G| > 60）**：应用先尝试 FastAPI 后端；后端没启动时回退到本地计算
  （≤ 240 阶，S₅ 约需 2–3 秒），慢任务顶部会出现进度条。开启快速路径：

  ```bash
  cd backend
  pip install -r requirements.txt
  uvicorn main:app --reload --port 8000
  ```

- **会话恢复**：当前群与视图自动持久化，刷新后回到原处；自定义作用草稿与展示草稿
  也会自动保存。
- **布局乱成一团**：手动切换 2D 形状（14 种）或 3D 形状（18 种）——直积/半直积群
  通常选圆柱/甜甜圈/重布线最好读。
- **超大群的子群**可能来自后端，右侧面板加载时会显示提示。
